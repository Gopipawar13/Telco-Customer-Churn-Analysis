# 📊 Telco Customer Churn Analysis

🚀 Interactive Power BI dashboard analyzing customer churn patterns and business insights.

## 🔍 Project Overview
This project analyzes customer churn behavior using Power BI.  
The dashboard provides insights into customer retention, revenue, and churn patterns.

---

## 📁 Dataset
- Telco Customer Churn Dataset
- Contains customer demographics, services, and billing information

---

## 📊 Key Insights
- Highest churn occurs in the first 12 months
- Month-to-month contracts have the highest churn rate
- Fiber optic users show higher churn behavior
- Long-term customers are more stable and loyal

---

- Excel
- Data Cleaning & Visualization
